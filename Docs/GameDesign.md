# 第一关核心玩法

范围于 2026-10-09 收窄：只做第一关核心玩法，不设计或制作主页、商城、设置、其他页面和后续关卡。

直接进入关卡。使用 Blender 输出的花朵、蜜蜂、小蜂巢和大蜂巢，不用 Unity 基础几何体替代主体模型。现有花朵458块，简化为粉324、黄84、绿50。模型由458个独立方块组成，保留可旋转观察与外域表层采集规则。

五列待选蜂巢：第一列粉108→粉108；第二列黄84；第三列绿50；第四列粉108；第五列空。五个工作槽保持完整。玩家点击列前端蜂巢，蜜蜂自动出发，每趟一块、每蜂巢最多三任务；取块扣额，归零释放槽，交付更新进度。

这是教学性质关卡，不设置倒计时或复杂死锁陷阱。屏幕只保留关卡标题、已交付进度、五槽、队列、简短操作提示和测试用本关重开。通关仅显示关内完成状态，不进入另一页面或下一关。

按 QFramework 的 Command→Model→System/事件→ViewController 实现；只一个 BeeHarvestApp。所有依赖注册在 Init，视图只发 Command 和读状态。

复核：同色采集、外露判定、预留不提前暴露、额度不超支、重复交付不重复计数、满槽仍可推进、最后一块交付才通关、暂停不推进。

不做本阶段存档、体力、金币、提示、其他页面、更多关卡或发行构建。首轮可玩验收在 Unity 编辑器；iPhone 真机验证另行进行。
